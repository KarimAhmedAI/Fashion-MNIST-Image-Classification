# Fashion-MNIST-Image-Classification
A Deep Learning project for classifying clothing items using TensorFlow and Keras.

This model was trained on the Fashion-MNIST dataset to classify grayscale images of clothing items into 10 categories such as T-shirts, shoes, bags, and more.

The project demonstrates a simple neural network pipeline for image classification tasks.

📊 Results
---
The model achieved:

Training Accuracy: ~89%
Validation Accuracy: ~88%
Test Accuracy: ~87%

⚙️ Technologies Used
---
Python
TensorFlow / Keras
NumPy
Matplotlib

✨ Features
---
Load and preprocess Fashion-MNIST dataset
Visualize sample images from dataset
Train a neural network for classification
Make predictions on test images
Display prediction probabilities for each class

📦 Dataset
---
Fashion-MNIST Dataset

70,000 grayscale images
10 classes of clothing items
Image size: 28×28 pixels

Classes:
---
T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot

🧠 Model Summary
---
A simple fully connected neural network:

Flatten input layer
Dense layers with ReLU activation
Dropout layer for regularization
Output layer with Softmax activation

🔍 Example Prediction
---
Predicted Class: Sneaker
Actual Class: Sneaker

The model successfully classifies clothing images with good accuracy for a beginner-level deep learning project.
